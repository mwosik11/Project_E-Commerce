# Temporal and Predictive Analytics for Data-Driven E-Commerce Decision Support

Group 8 research project on the UCI *Online Retail II* dataset: customers are grouped into RFM-based
behavioural states (K-Means), transitions between states are analysed, and the next state is predicted
with Logistic Regression, Random Forest and XGBoost, comparing a configuration with current information
only (Config A) against one that also uses state history (Config B).

## Repository layout

| Path | Content |
|---|---|
| `notebooks/01_data_preparation.ipynb` | Cleaning, snapshot-aware cancellation handling, customer-snapshot panel |
| `notebooks/02_state_construction.ipynb` | log1p + scaling, choice of k (Elbow), frozen K-Means state model |
| `notebooks/03_transitions_and_dataset.ipynb` | Transition matrices, Markov-order tests, prediction dataset |
| `notebooks/04_predictive_modeling.ipynb` | Temporal tuning, LR / RF / XGBoost, benchmarks, evaluation |
| `notebooks/05_hypothesis_testing.ipynb` | Paired customer-level bootstrap, H1 / H2 |
| `notebooks/06_decision_support.ipynb` | Risk × value targeting of customers and budget-constrained campaign simulation |
| `notebooks/07_robustness_checks.ipynb` | Stop-model specification and K-Means ablation, results by test origin, G-test by origin |
| `experiments/rfm_window_180d/` | Sensitivity analysis with 180-day window RFM, k = 4 and k = 3 (see its README) |
| `src/` | Shared helpers (`config.py`, `states.py`, `k_selection.py`, `dataset.py`, `modeling.py`, `bootstrap.py`, `decision.py`) |
| `data/` | Intermediate (`interim/`) and processed (`processed/`) data generated by the notebooks |
| `models/` | Frozen state model and the six trained classifiers |
| `outputs/` | Result tables (`tables/`) and figures (`figures/`) used in the report |
| `reports/` | Final project report (`MSIS4133.R12.CTTT_Group08_Final_Report.docx`) |
| `online_retail_II.xlsx` | Raw UCI Online Retail II data (input to notebook 01) |
| `online_retail_II_cleaned.xlsx` | The group's earlier static cleaning, used only for validation in notebook 01 |

## How to reproduce

1. `pip install -r requirements.txt`
2. The raw dataset `online_retail_II.xlsx` (UCI Machine Learning Repository,
   https://archive.ics.uci.edu/dataset/502/online+retail+ii, CC BY 4.0) is included in the project root.
3. Run the notebooks in order, 01 → 07. All randomness uses seed 42.
4. Optional: run the scripts in `experiments/rfm_window_180d/` for the rolling-window sensitivity analysis (k = 4, and again with `WINDOW_K=3`).

Intermediate data (`data/`) and trained models (`models/`) are included so results can be inspected without re-running; the notebooks regenerate them.
